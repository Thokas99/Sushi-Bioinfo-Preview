# Synthetic example files

These are **illustrative test fixtures, not biological observations**.

- `example.csv`: differential-expression-style values.
- `example.tsv`: single-cell metadata.
- `example.vcf`: minimal VCFv4.3.
- `example.bed`: simple genomic intervals.
- `example.gff3`: synthetic gene, transcript, and exon features.
- `example.mtx`: small sparse Matrix Market coordinate matrix.
- `example.vcf.gz`: compressed VCF fixture. **Only gzip metadata** is shown by the previewer.

Select any file in Nautilus and press **Space** to inspect its preview.
